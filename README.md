# Аналитический движок и ООП-обработчик киноданных (MovieLens)

Этот проект представляет собой автоматизированное решение для сбора, предобработки и комплексного анализа данных о кинематографе. В нем сочетаются инженерный подход с использованием объектно-ориентированного программирования (ООП) на Python и глубокий исследовательский анализ данных (EDA).

## Ключевые возможности
* **Объектно-ориентированная архитектура (ООП):** Логика обработки структурирована внутри кастомных классов на Python для обеспечения масштабируемости и чистоты кода.
* **Автоматизация и отказоустойчивость:** Скрипты включают обработку исключений и безопасное чтение данных, минимизируя сбои при выполнении.
* **Исследовательский анализ (EDA):** Подробный разбор датасета MovieLens для выявления скрытых паттернов, популярных жанров и трендов в поведении пользователей.
* **Юнит-тестирование:** Бизнес-логика классов покрыта автоматическими тестами, что гарантирует стабильность работы и корректность расчетов.

## Технологический стек
* **Язык программирования:** Python 3.9
* **Анализ данных и EDA:** Pandas, NumPy, Matplotlib, Seaborn
* **Тестирование:** PyTest / Unittest
* **Среда исполнения:** Jupyter Notebook, автономные Python-скрипты

## Структура репозитория
* `movielens_analysis.py` — основной производственный скрипт с реализацией классов и бизнес-логики обработки.
* `movielens_report.ipynb` — интерактивный Jupyter-ноутбук с визуализациями, расчетом метрик и выводами EDA.

## Выявленные аналитические инсайты
* Проанализировано распределение пользовательских оценок по различным историческим жанрам кино.
* Выявлены демографические и поведенческие паттерны пользователей при взаимодействии с рекомендательными системами кинофильмов.
